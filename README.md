# Wine Quality Predictor

Веб-приложение на Streamlit для оценки вероятности того, что вино относится к категории хороших, по его физико-химическим характеристикам. Прогноз строится с помощью логистической регрессии, обученной на данных о качестве красных и белых вин.

## Возможности

- **Оценка одного вина:** ввод характеристик и получение вероятности положительного класса.
- **Метрики модели:** precision, recall, F1, матрица ошибок, ROC- и PR-кривые с учётом выбранного порога.
- **Пакетное предсказание:** загрузка CSV с характеристиками вин и экспорт прогнозов.
- **Коэффициенты модели:** визуализация коэффициентов логистической регрессии для стандартизированных признаков.

Порог классификации меняется ползунком в боковой панели. Значение по умолчанию хранится в `config.json`.

## Технологии

Python, Streamlit, scikit-learn, pandas, NumPy, matplotlib и joblib.

## Локальный запуск

Требуется Python 3.13. Из каталога приложения:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

После запуска приложение доступно по адресу `http://localhost:8501`.

## Входные данные

Для пакетного предсказания загружается CSV с теми же 12 признаками, которые использовались при обучении модели. Названия столбцов должны совпадать с названиями в `test.csv`; столбец `target` при загрузке не требуется. Результат содержит исходные данные, столбец `probability` с вероятностью хорошего вина и `recommend` с бинарным решением при выбранном пороге.

## Особенности реализации

Модель загружается из `model.joblib` без повторного обучения. Для уменьшения повторных вычислений используются `st.cache_resource` и `st.cache_data`. Содержимое вкладок загружается по мере открытия, что сокращает использование памяти при работе в Streamlit Community Cloud.
