# Подбор хороших вин — приложение Streamlit

## Запуск

Используется **Python 3.13**. Откройте терминал в папке `wine_app` и выполните:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере. Рядом с `app.py` должны находиться `model.joblib`, `config.json` и `test.csv` — они уже включены в папку. До запуска ничего обучать не нужно.

## Возможности

- **Одно вино:** 12 признаков, включая переключатель красного/белого вина; вероятность и рекомендация с учётом порога.
- **Модельные метрики:** матрица ошибок, precision, recall, F1, ROC- и PR-кривые с точкой выбранного порога.
- **Пакетное предсказание:** загрузка CSV, таблица прогнозов и скачивание результатов. Нужны те же 12 столбцов, что в `test.csv`, **без** `target`.
- **Коэффициенты:** влияние стандартизированных признаков на предсказание.

Порог по умолчанию берётся из `config.json` (0.268), а в приложении меняется ползунком в боковой панели.

## Зачем нужен кэш

`st.cache_resource` используется для модели, потому что она является одним общим объектом, который не нужно загружать с диска заново при каждом действии. `st.cache_data` подходит для таблицы и рассчитанных вероятностей, потому что это данные, которые не меняются при движении ползунка. При новом пороге меняются только метки классов и рассчитанные по ним метрики. Если вызвать `joblib.load` без кэша, Streamlit будет снова читать файл модели при каждом обновлении страницы.

## Публикация в Streamlit Community Cloud

1. Создайте репозиторий на GitHub и загрузите в него папку `wine_app` целиком (все шесть файлов).
2. Зайдите на [share.streamlit.io](https://share.streamlit.io/), авторизуйтесь с GitHub и выберите репозиторий и главную страницу `wine_app/app.py` (или `app.py`, если файлы лежат в корне репозитория).
3. Выберите Python 3.13, если платформа предлагает выбор версии, и запустите публикацию.
4. Откройте выданную ссылку, проверьте работу вкладок и вставьте адрес в конец ноутбука перед сдачей.
